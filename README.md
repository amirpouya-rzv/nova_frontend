# 🛍️ Nova Shop

A modern and responsive e-commerce website built with Next.js, React, and TypeScript.

## About

Nova Shop is an e-commerce frontend project developed to practice modern frontend development and build a user-friendly online shopping experience.

## Features

- Responsive design
- Product listing and product details
- Product categories
- Product search and sorting
- Pagination
- Dark and light mode
- REST API integration
- Server-Side Rendering (SSR)

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Redux Toolkit
- Axios
- React Icons
- Shadcn Ui

## Installation

Clone the repository:

```bash
git clone https://github.com/amirpouya-rzv/nova_frontend
```

Navigate to the project directory:

```bash
cd nova_frontend
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

**Note:** The backend API must be running on `http://localhost:4000` for local development.
